# 📊 Social Media Engagement & Sentiment Analytics

## 📌 Project Overview

Social Media Engagement & Sentiment Analytics is a Data Analytics project that analyzes customer opinions from social media platforms using Natural Language Processing (NLP) and visualizes insights through Power BI dashboards.

The project helps businesses understand customer sentiment, monitor brand reputation, and analyze engagement metrics such as likes, shares, and follower growth.

---

## 🎯 Objectives

* Analyze social media comments and mentions.
* Perform sentiment analysis using NLP.
* Classify comments into Positive, Negative, and Neutral categories.
* Calculate engagement metrics.
* Compare brand performance across platforms.
* Build interactive Power BI dashboards.
* Generate business insights for decision-making.

## 📊 Dataset Description

The dataset contains social media engagement data collected from different platforms.

### Dataset Fields

| Column    | Description                  |
| --------- | ---------------------------- |
| Date      | Date of Comment              |
| Platform  | Instagram, Facebook, Twitter |
| Brand     | Brand Name                   |
| Comment   | Customer Feedback            |
| Likes     | Number of Likes              |
| Shares    | Number of Shares             |
| Followers | Number of Followers          |

---

## 🔍 Sentiment Analysis

Sentiment Analysis is performed using the NLTK VADER Sentiment Analyzer.

### Sentiment Categories

| Sentiment | Score         |
| --------- | ------------- |
| Positive  | > 0.05        |
| Neutral   | -0.05 to 0.05 |
| Negative  | < -0.05       |

---

## 📈 Key Performance Indicators (KPIs)

### Engagement Rate Formula

```text
Engagement Rate = ((Likes + Shares) / Followers) × 100
```

### KPIs Used

* Total Mentions
* Positive Comments
* Negative Comments
* Neutral Comments
* Average Engagement Rate
* Follower Growth Rate

* Most social media comments were Positive.
* Instagram showed the highest engagement rate.
* Nike received the highest number of mentions.
* Adidas showed strong customer satisfaction.
* Negative comments were mainly related to pricing and customer support.
